Blueprint de Replicación para IA

Este documento contiene el 100% de los códigos escritos de la aplicación "El Grupito Pequeño" para permitir a otra IA reproducir la estructura exacta del sistema.

Framework & Plataforma React 19 + Vite + TypeScript

Base de datos y Cache Firebase Firestore + LocalStorage Cache
Filtros Principales Agrupados por Pastor y Año (Por separado)

Descripción de la Arquitectura

La aplicación está diseñada bajo el patrón Single Page Application (SPA) modular. Su propósito es servir como un lector offline resiliente para sermones de diversos pastores y expositores de la comunidad (tales como el Pastor Daniel Gómez, la Misionera Elena Castro o el Pastor Marcos Benítez) organizados por año por separado. Se organiza en base a tres núcleos principales:

  • Types (Tipos de datos): Una interfaz estricta en TypeScript que define las entidades Message (Sermón) y Series (Colección por Pastor y Año).
  • Firebase Middleware: Un puente robusto que encapsula los intentos de red hacia las colecciones de Firestore y maneja errores de permisos de manera granular con diagnósticos visibles en la UI.
  • UI & Lector de Pantalla Completa: Componentes desacoplados que permiten leer Markdown, ajustar tamaños de fuente, gestionar marcadores de favoritos y registrar notas de estudio locales.
